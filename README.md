# ⭐ The Prabhas Universe

> *"Star ante Rebel a ra, Rebel ante Raaje ra..."*

A fan-built cinematic archive celebrating the legacy of **Prabhas** — the Rebel Star of Indian cinema. From *Eeswar* (2002) to *Kalki 2898 AD*, explore every era of his journey through an interactive, single-page experience.

## ✨ Features

| Section | Description |
|---|---|
| 🎬 **Filmography** | Complete movie collection with live search and category filters (Blockbusters, Action/Sci-Fi, Vintage/Romance) |
| 💰 **Box Office Dashboard** | Worldwide gross estimates for India's biggest blockbusters |
| 🖼️ **Photo Gallery** | Iconic posters with a full lightbox — zoom in/out, reset, fullscreen & navigation |
| ⏳ **Timeline** | The evolution from debutante to global icon |
| 🏆 **Awards & Honours** | The Rebel Star's trophy cabinet |
| 📰 **The Chronicles** | Articles, records and stories from the journey |
| 🧠 **Rebel Star Quiz** | Interactive quiz — prove you know everything about Prabhas |
| ✨ **Extras** | Animated particle hero, scroll progress bar, stats counters, back-to-top |

## 🛠️ Tech Stack

- **HTML5** — semantic, single-page layout
- **CSS3** — custom animations, responsive design, glassmorphism
- **Vanilla JavaScript** — no frameworks, no build step
- **Google Fonts** — Cinzel + Inter
- **Font Awesome 6.5** — icons

## 📁 Project Structure

```
prabhas-universe/

```

## 🚀 Getting Started

No build tools or dependencies required — just open it:

```bash
git clone https://github.com/indukurirushwanth-coder/prabhas-universe.git
cd prabhas-universe
```

Then open `index.html` in your browser, or serve it locally:

```bash
# Python
python -m http.server 8080

# VS Code
# Install "Live Server" extension → Right-click index.html → Open with Live Server
```
